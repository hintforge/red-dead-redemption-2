# Red Dead Redemption 2 -- Dreamcatchers (20)

**status:** research-integrated
**last_reconciled:** 2026-10-30
**research_run:** P1 2026-10-30; P2 2026-10-30

No strand giver. Rows are keyed on the nearest named landmark and the in-game map lettering; no source publishes coordinates, so none are given here.

- Inspect each dreamcatcher hung in a tree. When all 20 are found, a journal drawing connects them; the animal's "eye" points to the cave behind the Elysian Pool waterfall, where the Ancient Arrowhead lies (bring a lantern). The reward perk makes bow stamina last twice as long. Not missable; available from Chapter 2. The task can stay in the log after completion, and selling the arrowhead reportedly leaves the quest uncleared.
