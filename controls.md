# Red Dead Redemption 2 -- Controls

**status:** research-integrated
**last_reconciled:** 2026-10-30
**research_run:** P1 2026-10-30

Platform for this guide: PC / Steam (keyboard and mouse; controller where sources cover it). The default key map itself was not recovered; accessibility-rebind discussion was not found. [gap]

- Keyboard and mouse remapping exists, but the Key Mapping option appears only during gameplay; up to two keys can be bound per action; the Home key is reserved for the launcher overlay.
_source: https://www.pcgamingwiki.com/wiki/Red_Dead_Redemption_2 (P1 research 2026-10-30) · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:community-wiki]

- Forced mouse smoothing with weapons holstered, and camera stutter on horseback, cannot be disabled in settings; a community mod ("Mouse Smoothing Fix") removes it. The Mouse Smoothing setting has 3 positions.
_source: https://www.pcgamingwiki.com/wiki/Red_Dead_Redemption_2 (P1 research 2026-10-30) · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:community-wiki]

- Keyboard run is not a toggle by default; a community mod ("Toggle Run On Keyboard Fix") adds a console-style toggle.
_source: https://www.pcgamingwiki.com/wiki/Red_Dead_Redemption_2 (P1 research 2026-10-30) · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:community-wiki]

- Controller: 12 remap presets per view; separate look and aim sensitivity (15 positions), acceleration and dead-zone adjustment; DualShock 4 works natively with Steam Input disabled; DualSense is not supported out of the box.
_source: https://www.pcgamingwiki.com/wiki/Red_Dead_Redemption_2 (P1 research 2026-10-30) · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:community-wiki]

- Eagle Eye (highlight collectibles) is L3 plus R3 on a controller.
